# GramaVaxi – Livestock Vaccination Management System

GramaVaxi is an Android application developed to help farmers and veterinary workers manage livestock vaccination records efficiently. The application provides a simple and user-friendly interface for storing animal details, vaccination schedules, and tracking vaccination history digitally.

## Features

- Farmer Login System
- Dashboard for Navigation
- Add Animal Details
- Store Vaccination Information
- Vaccination Date Tracking
- Next Due Date Management
- Simple User Interface
- Android Based Application
- Firebase Ready Structure

## Modules

### Login Module
Allows users to securely access the application.

### Dashboard Module
Provides navigation to different sections of the application.

### Add Animal Module
Stores:
- Animal Name
- Animal Type
- Owner Name
- Village Name
- Vaccine Date

### Vaccination Module
Stores:
- Animal ID
- Vaccine Name
- Vaccination Date
- Dosage
- Veterinarian Details
